Make two changes to SealedDelivery, retest, rescan and redeploy with the same constructor arguments.

1. Silence costs the seller twice. A claim reserves min(2 * promise.value, coverage(seller)). On finalize, the buyer's claimable balance gets half of the reservation, rounded up, and the other half goes to the fixed address 0x000000000000000000000000000000000000dEaD through SafeERC20, so no one can recover it. This makes a seller who pays itself through a second address lose half of whatever it pulls, while requestWithdraw after the cooldown costs nothing. Add a test that runs that self-dealing path and shows the loss. Add a public view coverageFor(seller, value) that returns true when coverage(seller) >= 2 * value, so a buyer can read it before paying.

2. Add prove(claimId, ciphertext, key). Anyone may call it on a claim that is open or DELIVERED, as long as it was not already marked FRAUD. It requires keccak256(abi.encodePacked(key)) == keyHash and keccak256(ciphertext) == ciphertextHash. It decrypts with this exact keystream: for block i starting at 0, keccak256(abi.encodePacked(key, uint256(i))), XORed with each 32-byte chunk of the ciphertext, with the last chunk truncated to length. If keccak256(plaintext) == plaintextHash it reverts with PromiseKept. Otherwise it marks the claim FRAUD, increments fraudCount[seller], applies the same two-part payout as silence and emits Fraud(claimId, paymentNonce, seller, buyer, paidOut). If the claim was already DELIVERED, its reservation was released at answer, so take the amount from whatever coverage is left at that moment. Add a cross-check fixture at contracts/test/fixtures/sealed-vector.json with key, plaintext, ciphertext and the hashes, and a test that reads it. Also write the same keystream in TypeScript at src/lib/sealed.ts with sealResponse(plaintext) and openResponse(ciphertext, key), and a test proving that the bytes match the fixture. Report the largest ciphertext that prove handles under the block gas limit, measured with forge.

Do not change the rest of the app in this turn. Report the address, the test count, every remaining scan finding, and the deploy transaction.
